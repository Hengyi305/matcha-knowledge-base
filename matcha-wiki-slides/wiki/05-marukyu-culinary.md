# 丸久小山園：食品烘焙與飲品加工選茶指南

製作拿鐵或烘焙甜點時，若使用高階濃茶會導致茶味被牛奶與高溫掩蓋，且成本過高；應依「加熱溫度」與「乳脂糖分比例」挑選專屬食品級茶款。

| 茶款名稱 | 等級定位 | 風味與色澤表現 | 最佳應用場景 |
| :--- | :--- | :--- | :--- |
| **若竹（Wakatake）** | 食品用最高階（烘焙界公認首選） | 甘甜與澀味完美平衡，色香味堪比茶道用抹茶，**高溫加熱後色澤依然鮮豔翠綠**。 | 蛋糕、生乳捲、慕斯、冰淇淋、抹茶拿鐵（全溫域通用）。 |
| **綠樹（Midorigi）** | 入門至中階烘焙茶 | 帶有清新茶香，口味相對清淡，經糖分與奶油中和後苦澀感消失（不適合單喝）。 | 經濟實惠的低溫與高溫烘焙。 |
| **白蓮（Byakuren）** | 乳製品與冷飲特化款 | 粉末細緻、性質穩定，苦味低帶淡淡青草香；與牛奶混合時能保留乾淨茶香不被奶味蓋過。 | 抹茶拿鐵、鮮奶油打發、冷飲調製。 |
| **龍膽（Rindou）** | 高溫重烘焙／重茶感拿鐵用 | 色澤偏黃、苦澀味明顯、缺乏鮮味，茶感強烈。 | 麵包、貝果、曲奇、巧克力，或喜歡豪邁加粉壓過奶味的拿鐵控。 |
| **水仙（Suisen）** | 食品加工中階款 | 位於龍膽與菖蒲之間的標準加工用等級[cite: 1]。 | 一般常溫烘焙與食品加工配方。 |
| **菖蒲（Ayame）** | 高溫重油重甜烘焙用 | 茶味偏重、明顯草味與強烈苦澀感，茶湯色澤沉靜乾淨，幾乎不回甘。 | 高糖高油脂甜點（舒芙蕾鬆餅、磅蛋糕、吐司、濃郁鮮奶油）。 |
| **東和（Towa）** | 烘焙用基礎入門款（性價比最高） | 等級最低但仍保有接近柳綠色的色澤（非廉價枯黃色），提供基礎抹茶香氣。 | 大量生產、需加大量糖與乳製品的基礎烘焙。 |
| **不哭抹茶（泣かない抹茶）** | 特殊防潮裝飾專用（分特選／德用） | 苦澀味較重，具備**不吸濕性**，罐裝內附濾網便於直接過篩。 | 直接灑在提拉米蘇、生乳捲、蛋糕表面裝飾，久放不受潮變色。 |
